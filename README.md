# Offline Trek Buddy (SurviveIt)

An essential, offline-first survival toolkit built for outdoor enthusiasts, hikers, and trekkers. Everything you need to navigate, prepare, and stay safe in the wilderness without requiring an active internet connection.

## 🌟 Key Features

- 🧭 **Compass & Location**: Digital compass with heading degree, cardinal directions, latitude, longitude, and elevation.
- 🗺️ **Offline Map**: Interactive mapping utility designed to function offline.
- 📚 **Survival Guide**: Essential wilderness survival guides, medical first aid tips, and emergency strategies.
- 🚨 **SOS Emergency Beacon**: Quick access screen for triggering visually urgent emergency distress signals and sound cues.
- 📋 **Trip Checklist**: Interactive, persistent checklist to track gear, food, water, and essential equipment before setting off.

## 🛠️ Technology Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [Radix UI](https://www.radix-ui.com/) & [shadcn/ui](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **State & Data**: [TanStack Query (React Query)](https://tanstack.com/query)
- **Routing**: [React Router DOM v6](https://reactrouter.com/)

## 🚀 Quick Start

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) and `npm` installed.

### Installation & Development

```bash
# 1. Install dependencies
npm install

# 2. Start the local development server
npm run dev

# 3. Open http://localhost:8080 in your browser
```

### Production Build

```bash
# Build for production
npm run build

# Preview production build locally
npm run preview
```
